Test certificates (certs/)

  test-root-ca-key.pem   root CA private key (PKCS#1, RSA-2048) - kept, never regenerated
  test-root-ca.pem       self-signed test root CA (v3, CA:TRUE, keyCertSign, SKID)
  test-server-key.pem    server private key (PKCS#8, RSA-2048) - kept; also embedded verbatim
                         in src/utests/include/utests/baselib/UtfCrypto.h (getDefaultServerKey)
  test-server-req.pem    server CSR: C=US/ST=New York/L=NYC/O=My Company Ltd/CN=*.*.mycompany.com
                         - kept and reused so the DN and SANs stay identical
  test-server-cert.pem   server certificate signed by the root, extensions from [ v3_req ] in
                         certs/openssl.conf (CA:FALSE, keyUsage, SAN)
  openssl.conf           request config; [ v3_req ] / [alt_names] define the server extensions
  test-server-ip-*.pem   self-signed certificate used by the TlsPeerVerification tests and,
                         with its key, as the untrusted server certificate of the TlsHandshake
                         tests; see certs/ip-openssl.conf for how it was generated
  CAs/                   public root CAs

Procedure

  The certificates are regenerated with certs/regenerate-test-certs.sh (plain sh + openssl).
  It keeps the keys and the CSR, issues both certificates for 10000 days, and verifies the
  chain at -auth_level 2 (the level the library enforces via SSL_CTX_set_security_level).

  After running it, re-embed the two new PEM files as the string literals getDevRootCA() and
  getDefaultServerCertificate() in UtfCrypto.h (one "<line>\n" C string per PEM line, 16-space
  indent, ';' after the END line) and confirm the embedded text is byte-identical:

    diff <(sed -n '/getDevRootCA/,/^        }/p' src/utests/include/utests/baselib/UtfCrypto.h \
        | grep '^ *"' | sed -e 's/^ *"//' -e 's/\\n";*$//') certs/test-root-ca.pem

  (same for getDefaultServerCertificate vs certs/test-server-cert.pem); both must print nothing.

Constraints

  DNS:*.*.mycompany.com must remain the FIRST subjectAltName and DNS:localhost the second.
  src/utests/utf_baselib_http/TestTlsPeerVerification.h asserts that a wildcard spanning more
  than one label matches nothing, and the http/messaging/rest TLS tests connect to localhost.
  Security level 2 requires RSA >= 2048 and SHA-256; the keys and the sha256WithRSA signatures
  already satisfy it.
